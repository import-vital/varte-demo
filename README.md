# “Varte” - One-page website

Educational project: a landing page for a conscious-reading service and Trade-In program.

**Demo:** https://import-vital.github.io/varte-demo/

## What's inside
- Responsive layout for desktops, tablets, and smartphones
- CSS-only burger menu
- Sections with a background image and background video
- Contact form and book catalog table
- Three subscription plan cards
- Trade-In, FAQ, and customer review sections
- CSS entrance animations and transitions

## Technologies
HTML5, CSS3, JavaScript, Flexbox, Grid, media queries, and Web3Forms. No frameworks or libraries.

## Structure
```
index.html      main page
css/style.css   all styles
img/            images
video/          background video
```
